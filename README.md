# Anuj Kumar Singh — Reference-Inspired Portfolio

A static HTML/CSS/JavaScript portfolio closely modeled on the interaction patterns and visual language of the supplied reference site:
`https://hariratan.netlify.app/`

## Included
- Full-screen boot/loading sequence with animated progress.
- Futuristic dark terminal aesthetic with green accent.
- Inline SVG particle/network background and animated orbit decorations.
- Sticky navigation with active-section highlighting and mobile menu.
- Hero section with typewriter animation and Anuj's supplied photo.
- Featured project presentation.
- Skills & Arsenal section based on the supplied CV.
- Project cards with filters and interactive detail modal.
- Education & Journey timeline based on the supplied CV.
- All five supplied certificates with full-size preview modals.
- Interactive portfolio terminal with commands.
- Contact section using the CV email, GitHub, LinkedIn and phone number.
- Resume PDF linked throughout the site.
- Responsive layout for desktop, tablet and mobile.

## Run locally
Open `index.html` directly, or use a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
The folder is static and can be deployed to GitHub Pages, Netlify, Vercel or any static hosting service.
